로그인과 계정 기록

네이버·카카오 로그인에서 동의한 이용자 식별자를 Supabase 인증 서비스로 전달하여 업바이블 계정을 구분합니다. iPhone의 Apple 로그인을 사용하는 경우 Apple 이용자 식별자와 동의한 이메일(이메일 가리기 주소 포함)을 인증 서비스에 전달합니다. 서비스 자체 비밀번호는 받지 않습니다.

내 계정에서 기록 동기화를 누르면 읽던 위치, 좋아요, 저장한 구절, 개인 댓글, 글자 크기를 Supabase의 계정별 저장소에 전송합니다. 로그인만으로 기존 비로그인 기록을 올리지는 않습니다. 댓글은 다른 사용자에게 공개되지 않습니다. 계정별로 기록을 분리하며 서버에 보관된 기록은 다른 기기에서 같은 계정으로 불러올 수 있습니다.

회원 탈퇴와 연결 해제

앱의 내 계정에서 회원 탈퇴를 확인하면 업바이블 계정과 서버에 동기화된 기록을 삭제합니다. 현재 기기의 해당 계정 기록과 내부 백업도 삭제합니다. Apple로 가입한 계정은 탈퇴 시 Apple과의 연결도 함께 해제합니다. 다른 기기나 브라우저에 남은 사본, 비로그인 기록, 직접 공유한 사본은 별도로 삭제해야 합니다. 서비스 제공자의 백업·보안 로그 보관은 해당 서비스 정책을 따릅니다.

업바이블 계정 삭제와 별도로 네이버·카카오 설정에 남은 서비스 연결을 해제할 수 있습니다. 다시 로그인하면 새 업바이블 계정이 생성될 수 있습니다.

공유 기능

공유하기를 선택하면 성경 구절과 출처가 기기의 공유 기능을 통해 사용자가 선택한 앱이나 수신처에 전달됩니다. 이후 정보 처리는 선택한 서비스의 정책을 따릅니다.

기록 삭제와 백업

좋아요와 저장은 각 항목에서 취소할 수 있으며 댓글은 해당 구절의 댓글 화면에서 삭제할 수 있습니다. 설치 앱을 삭제하면 해당 기기에 저장된 기록이 삭제됩니다. 서버에 동기화한 기록은 회원 탈퇴 전까지 계정에 남습니다.
